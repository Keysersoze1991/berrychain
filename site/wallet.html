Set up a wallet for BERRY

A BerryChain wallet is one small file on your PC, sealed with a passphrase. It holds the keys that control an address. There is no account, no sign-up and no company holding your coins: the file and the passphrase are the whole thing. This page is click by click on Windows; Linux and Mac use the same commands with forward slashes.

What a wallet is, in one breath. An address that starts with brry1 is where coins are sent. The wallet file holds the private key that can spend from that address, encrypted under your passphrase. Anyone with the file and the passphrase controls the coins. Lose both the file and its backup, or lose the passphrase, and the coins are gone forever; nobody can reset them.

Part A: get the tools

If you've already followed the mining or add-your-LLM guide, you have these and can skip to Part B.

  1. Open PowerShell: Start button, type powershell, click "Windows PowerShell".
  2. Paste and press Enter, waiting for the prompt to return after each: 
    winget install --id Python.Python.3.12 --source winget --scope user --accept-package-agreements --accept-source-agreements
    winget install --id Git.Git --source winget --scope user --accept-package-agreements --accept-source-agreements
  3. Close PowerShell and open a new one.
  4. git clone https://github.com/Keysersoze1991/berrychain.git C:\berrychain
    cd C:\berrychain
    pip install -r requirements.txt

Part B: create the wallet

  1. Choose a name for it, for example savings. Paste and press Enter: 
    python -m berrychain.cli wallet new keys\savings.json --label savings --encrypt
  2. It asks for a new passphrase, then asks again. Nothing shows while you type. Use a long passphrase, five or six random words is ideal.
  3. It prints your new address, the line starting "address": "brry1. This is what you give to anyone who wants to send you BERRY, and what you paste into the miner or the LLM config. It's safe to share.

Part C: prove you can open it

Do this once, straight away. A wallet you can't unlock is worth nothing.

python -m berrychain.cli wallet check keys\savings.json

Type the passphrase. It should print "unlocked": true. If it says wrong passphrase, delete the file and start Part B again.

Part D: back it up

  1. Write the passphrase on paper and keep it somewhere other than with the PC.
  2. Copy the file C:\berrychain\keys\savings.json to a USB stick, or print it. The file is encrypted, so a copy is safe on its own; it's only useful with the passphrase.
  3. For a wallet that holds anything you'd hate to lose, create it on a USB stick in the first place, so the key never sits on an internet-connected disk: 
    python -m berrychain.cli wallet new E:\savings.json --label savings --encrypt
    Replace E: with the stick's drive letter. Keep the stick unplugged except when you're signing.

Part E: see your balance

Replace brry1… with your address. No passphrase is needed to look:

python -m berrychain.cli --node https://seed1.berrychain.link balance brry1…

Part F: receive BERRY

Give the sender your address. That's all. Mining rewards, grants, gifts and payments all arrive at the address; the wallet file doesn't need to be open, or even on a running PC, to receive.

Part G: send BERRY

Replace the address and the amount. Amounts can have up to eight decimal places, so 0.25 or 0.001 are fine. It asks for your passphrase, then prints a transaction id.

python -m berrychain.cli --node https://seed1.berrychain.link send keys\savings.json brry1… 0.25 --memo "thanks"

The minimum fee, 0.0001 BERRY, goes to the miner of the block. Sends are final once confirmed; check an address twice before pressing Enter.

Part H: an offline wallet you sign with

If the wallet lives on a stick you'd rather never plug into an online PC, sign on an offline machine and carry only the signed file across:

python -m berrychain.cli --node https://seed1.berrychain.link tx build transfer --from brry1YOURS… --to brry1THEIRS… --amount 0.25 --out unsigned.json

Copy unsigned.json to the offline machine, then there:

python -m berrychain.cli tx sign unsigned.json E:\savings.json --out signed.json

Copy signed.json back and send it:

python -m berrychain.cli --node https://seed1.berrychain.link tx send signed.json

Good habits

  • One wallet for everyday use with a small balance, one for keeping. Programs like the miner and the LLM tools only ever need the everyday one.
  • Never paste your passphrase into a chat, an email, or a web page. Nobody who runs BerryChain will ever ask for it.
  • The address is public; the file and passphrase are private. That's the whole rule.
